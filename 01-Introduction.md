# Introduction
1. Calculator can't do logical calculations but computer can.
2. Hardware is the physical component of a device which we can touch and feel.
3. Software is something that helps hardware to execute
   ## Types of software
   1. Operating software- something which directly interacts and manages device's hardware
      ### examples:-
      1. for bulb OS is electricity
      2. for car OS is fuel
   3. Application software- runs on top of operating software
      ### examples:-
      1. remote is application software for bulb
      2. start button in the car is application software
